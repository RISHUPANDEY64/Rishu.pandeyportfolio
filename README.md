# Rishu Pandey — Portfolio

A responsive dark/light developer portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — portfolio structure/content
- `style.css` — responsive design
- `script.js` — mobile menu, theme toggle and contact form
- `assets/profile.png` — profile photo

## Customize
Replace `#` links in `index.html` with your real GitHub, LinkedIn, Instagram and project URLs.
Put your real `resume.pdf` in the project root for the Resume buttons.
